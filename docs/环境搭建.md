# 环境搭建 · YOLOv10 官方代码运行环境

> **对应任务**：`任务拆解-YOLOv10-TT100K复现路径.md` 阶段 2.1（B 主责）。
> **目的**：让任意组员照此一步步把官方 YOLOv10 跑通推理。文末「踩过的坑」是搭建时实际遇到的问题，照着规避即可。
> **首次搭建环境**：Windows 11 + RTX 4070 12GB，Miniconda + Python 3.9 + PyTorch 2.0.1 (cu118)，已跑通推理。

---

## 0. 前置条件

- **GPU**：NVIDIA 显卡（首搭机为 RTX 4070 12GB）；驱动支持 CUDA ≥ 11.8（`nvidia-smi` 能看到显卡即可）。
- **Miniconda**：从 https://repo.anaconda.com/miniconda/ 下 `Miniconda3-latest-Windows-x86_64.exe` 安装。
  - 选 Miniconda 而非 Anaconda：体积小、环境干净、不预装用不到的包。
- **Git**。
- **（首搭机需要）本地代理**：首搭机访问 GitHub / PyPI / HuggingFace 不稳，全程走本地代理 `http://localhost:7897`。**若你的网络能直连，下面命令里的代理部分可全部去掉。**

---

## 1. 创建专用 conda 环境（Python 3.9）

```powershell
conda create -n yolov10 python=3.9 -y -c conda-forge --override-channels
```

- `-c conda-forge --override-channels`：强制走社区源 conda-forge，**绕开 Anaconda 默认源的 ToS 报错**（见坑 ①）。
- 环境与项目文件夹无关，按名字 `yolov10` 统一存在 `C:\Users\<你>\.conda\envs\yolov10`。
- 这个精简环境**默认不带 pip**，需补装（见坑 ②）：

```powershell
conda install -n yolov10 -y -c conda-forge --override-channels pip
```

> 之后所有 pip 命令都用环境自带的 python 调用，避免装错环境：
> `C:\Users\<你>\.conda\envs\yolov10\python.exe -m pip ...`
> （或先 `conda activate yolov10`，再直接用 `pip` / `python`。）

---

## 2. 克隆官方仓库

**克隆到项目同级目录，不要放进我们自己的 git 仓库里**（避免嵌套污染）：

```powershell
# 需代理时加 -c http.proxy / -c https.proxy（只对本次命令生效，不改全局）
git -c http.proxy=http://localhost:7897 -c https.proxy=http://localhost:7897 `
    clone https://github.com/THU-MIG/yolov10 D:\Project\yolov10
```

直连网络则简化为：`git clone https://github.com/THU-MIG/yolov10 D:\Project\yolov10`

---

## 3. 安装依赖

> 下面用环境变量给 pip 设代理（只在当前终端会话生效）；直连则去掉这两行 `$env:...`。

**① 先单独装 GPU 版 PyTorch**（`requirements.txt` 里的 `torch==2.0.1` 默认是 CPU 版，必须先从 cu118 源装 GPU 版，约 2.7GB）：

```powershell
$env:HTTP_PROXY="http://localhost:7897"; $env:HTTPS_PROXY="http://localhost:7897"
C:\Users\<你>\.conda\envs\yolov10\python.exe -m pip install `
    torch==2.0.1 torchvision==0.15.2 --index-url https://download.pytorch.org/whl/cu118
```

**② 再装其余依赖**（PyTorch 已满足，会自动跳过）：

```powershell
C:\Users\<你>\.conda\envs\yolov10\python.exe -m pip install -r D:\Project\yolov10\requirements.txt
```

**③ 把 yolov10 (ultralytics) 装成可调用包**：

```powershell
C:\Users\<你>\.conda\envs\yolov10\python.exe -m pip install -e D:\Project\yolov10
```

## 4. 验证

**① 确认 PyTorch 识别到 GPU**：

```powershell
C:\Users\<你>\.conda\envs\yolov10\python.exe -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```
期望输出：`2.0.1+cu118 True NVIDIA GeForce RTX 4070`

**② 跑一次推理**（权重从 HuggingFace 下，需代理；`device=0` 用 GPU）。把下面存成 `verify.py` 放到 `D:\Project\yolov10` 下运行：

```python
from ultralytics import YOLOv10

model = YOLOv10.from_pretrained("jameslahm/yolov10n")
results = model.predict("ultralytics/assets/bus.jpg", save=True, device=0)
print("DETECTED_BOXES:", len(results[0].boxes))
print("SAVE_DIR:", results[0].save_dir)
```

```powershell
$env:HTTP_PROXY="http://localhost:7897"; $env:HTTPS_PROXY="http://localhost:7897"
cd D:\Project\yolov10
C:\Users\<你>\.conda\envs\yolov10\python.exe verify.py
```

**通过标准**：检出 `4 persons + 1 bus`（5 个框），并在 `runs\detect\predict\bus.jpg` 生成带框结果图。✅ 首搭机已通过（GPU 推理 ~68ms/图）。

## 踩过的坑（照此规避）

| # | 现象 | 原因 | 解决 |
|---|------|------|------|
| ① | `CondaToSNonInteractiveError: Terms of Service have not been accepted` | Anaconda 默认源 `defaults` 需接受商业 ToS | 建环境时加 `-c conda-forge --override-channels`，全程走社区源 |
| ② | `No module named pip` | conda-forge 精简 Python 不自带 pip | `conda install -n yolov10 pip -c conda-forge` 补装 |
| ③ | clone / pip 频繁 `SSLEOFError` / `ProxyError` 断流 | 网络 / 代理偶发断连 | git 用 `-c http.proxy=...`，pip 用 `$env:HTTP_PROXY` / `$env:HTTPS_PROXY`；失败会自动重试，重试仍失败就重跑命令 |
| ④ | 上次中断后再 clone 提示「目录已存在 / branch broken」 | 残留半个 `.git` | `Remove-Item -Recurse -Force D:\Project\yolov10` 后重新 clone |
| ⑤ | 安装时一堆 `script xxx.exe is installed ... not on PATH` 警告 | 附带命令行工具没进 PATH | **无害**，我们用 `python -m` / `from_pretrained` 调用，可忽略 |

## 日常使用

每次开新终端先激活环境，之后 `python` / `yolo` 就是这套 3.9 环境：

```powershell
conda activate yolov10
```

不再需要时整体删除，不留垃圾、不影响系统 Python：

```powershell
conda env remove -n yolov10
```
