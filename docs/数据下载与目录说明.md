## 1. 官方下载地址

数据来自清华-腾讯官方页面：https://cg.cs.tsinghua.edu.cn/traffic-sign/
许可：**CC-BY-NC（仅非商业用途）**，课程作业属合规使用。

| 文件 | 直链 | 是否需要 | 说明 |
|------|------|:---:|------|
| **2016 标注数据** `data.zip` | https://cg.cs.tsinghua.edu.cn/traffic-sign/data_model_code/data.zip | ✅ **主用** | 含标注的图像 + `annotations.json`；45 类基准就建立在这一版上 |
| 2016 官方代码 `code.zip` | https://cg.cs.tsinghua.edu.cn/traffic-sign/data_model_code/code.zip | ⬜ 可选 | 官方读标注/可视化参考代码 |
| 2021 版 `tt100k_2021.zip` | https://cg.cs.tsinghua.edu.cn/traffic-sign/tt100k_2021.zip | ⬜ 备选 | 类别更全，标注文件名为 `annotations_all.json`；脚本同样兼容 |
| 无标志负样本 `nosign_1~5.zip` | .../data_model_code/nosign_1.zip … nosign_5.zip | ❌ **不要下** | 每个约 17GB、共 ~88GB，本项目用不到 |

> **建议**：只下 `data.zip`（2016 版）即可跑通全流程。想要更多类别再考虑 2021 版，**二选一**，别两版混用。

### 下载提示

- 服务器在清华（**国内**），**建议直连下载，不要走代理**（代理到国内站点反而更慢/可能失败）。
- 文件约 **10GB+**，强烈建议用**支持断点续传**的工具，断了能接着下：

```powershell
# 方式一：浏览器直接点直链下载（最简单）

# 方式二：PowerShell（不支持断点续传，仅小文件或网络稳定时用）
Invoke-WebRequest "https://cg.cs.tsinghua.edu.cn/traffic-sign/data_model_code/data.zip" -OutFile "D:\Project\data\data.zip"

# 方式三：aria2（推荐，多线程+断点续传；-x16 16线程，-c 续传）
aria2c -x16 -c -d D:\Project\data "https://cg.cs.tsinghua.edu.cn/traffic-sign/data_model_code/data.zip"
```

## 2. 解压与目录摆放

**把原始数据放在 git 仓库之外**（10GB+，不进版本库；仓库的 `.gitignore` 已屏蔽 `datasets/`）。
推荐放在与脚本输出**同一个盘 D:**（这样后续脚本能用硬链接零拷贝建数据集）。

```
D:\Project\data\TT100K\          ← 解压到这里（--data-root 指向它）
├── annotations.json             (2021 版则是 annotations_all.json)
├── train\    *.jpg              (图像以 id 命名，2048×2048)
├── test\     *.jpg
├── other\    *.jpg              (无关图，脚本自动忽略)
└── marks\                       (标志模板，用不到)
```

> `data.zip` 解压后通常是一个 `data\` 文件夹，把里面内容放到 `D:\Project\data\TT100K\` 下即可（或解压后直接把 `--data-root` 指到那个 `data\` 目录）。

### 解压后自检（任务 2.2.2）

```powershell
# 确认标注文件与三个图像目录都在
Get-ChildItem D:\Project\data\TT100K
# 抽查图像可读、数量
(Get-ChildItem D:\Project\data\TT100K\train -Filter *.jpg).Count
```

## 3. 跑数据准备脚本

确认在已搭好的环境里（见 `docs/环境搭建.md`）：

```powershell
conda activate yolov10
cd D:\Project\deep-learning-cv-practice

# ① 统计类别 + 按 >=100 实例筛子集（产出 scripts/tt100k_classes.txt 与计数 CSV）
python scripts\filter_tt100k.py --ann D:\Project\data\TT100K\annotations.json

# ② 转 YOLO 格式 + 划分 + 生成 yaml（默认输出到 datasets\tt100k，已被 .gitignore 屏蔽）
python scripts\tt100k_to_yolo.py --data-root D:\Project\data\TT100K
```

产物：

```
datasets\tt100k\
├── images\{train,val,test}\*.jpg     (硬链接自原始数据，几乎不占额外空间)
├── labels\{train,val,test}\*.txt     (YOLO 格式标注)
└── tt100k.yaml                        (训练时 data= 指向它)
```

> **硬链接前提**：原始数据与 `datasets\` 在同一盘（都在 D:）。若分属不同盘，脚本会自动回退为复制；也可显式 `--link-mode copy`。

### 加载验证（阶段 2.2 出口）

```powershell
# 用官方代码加载 1 个 epoch，确认数据/yaml 无误（不必收敛）
python -c "from ultralytics import YOLOv10; YOLOv10('yolov10n.yaml').train(data='datasets/tt100k/tt100k.yaml', epochs=1, imgsz=640, batch=4)"
```

跑通不报错即说明数据准备完成，可进入任务 2.2.7（抽样可视化）与阶段 2.3（训练脚本）。
